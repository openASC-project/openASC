# Project instructions

- Commit and push every completed change to the configured GitHub remote after the checks appropriate to that change pass. Do not accumulate completed work only in the local checkout.
- Keep commit messages, source documentation and website content in English.
- Keep original game files, third-party mods and generated local research reports out of Git.
- Keep the full openASC engine goal active until its actual requirements are implemented and verified. Report remaining limitations accurately.
