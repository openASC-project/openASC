A project at the beginning

A native Rust KN5 reader and wgpu diffuse renderer are available alongside the Python content tools and WebGL scene viewer. Supported diffuse textures, approximate transparency, typed surfaces, ground queries, car configuration readers and geometric spawn checks are available. A keyboard-controlled first-drive prototype is now locally tested. Original physics and shaders remain unvalidated. Finding a file does not establish compatibility.

What is openASC?

openASC is an open-source effort targeting 1:1 behavioral compatibility with Assetto Corsa (2014): physics, controls and FFB, visuals, audio, AI, sessions, networking and original content behavior. Inspired by the approach of openOMSI, development proceeds through documented formats and comparisons against the original game.

The first native Rust KN5 reader and wgpu renderer now load real local geometry and render supported embedded diffuse textures independently of Python and the browser. The existing Python/WebGL prototype supports a first keyboard drive. Neither path establishes original simulator parity. A native desktop inspection window now shares the renderer; static models.ini assembly now loads multiple models. A native rigid-body kernel now adds explicit 3D inertia, forces and fixed ticks. Original material fidelity, vehicle force laws and FFB remain work ahead.

Inside openASC

Actual openASC captures from local Drift, Magione and BMW M3 E30 tests on 17–18 October 2026. The browser driving images show an independent keyboard prototype with approximate materials and geometric road attachment. Static WALL meshes now contact an upright body proxy. Full convex/6DOF collision, suspension dynamics, wheel animation, sound and FFB remain unimplemented.
