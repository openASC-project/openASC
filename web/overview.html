A project at the beginning

A native Rust KN5 reader and wgpu diffuse renderer are available alongside the Python content tools and WebGL scene viewer. Supported diffuse textures, approximate transparency, typed surfaces, ground queries, car configuration readers and geometric spawn checks are available. A native Rust keyboard-driving workbench now couples chassis, suspension, wheel spin, road contact and steering to a moving GPU car root. Its diagnostic control/readback tests pass; physical keyboard use remains outside independent verification. Original physics and shaders remain unvalidated. Finding a file does not establish compatibility.

What is openASC?

openASC is an open-source effort targeting 1:1 behavioral compatibility with Assetto Corsa (2014): physics, controls and FFB, visuals, audio, AI, sessions, networking and original content behavior. Inspired by the approach of openOMSI, development proceeds through documented formats and comparisons against the original game.

The first native Rust KN5 reader and wgpu renderer now load real local geometry and render supported embedded diffuse textures independently of Python and the browser. The native window now supports keyboard throttle/brakes and smooth rack steering with an independent coupled physics model. The Python/WebGL driving prototype remains available. Neither path establishes original simulator parity. A native desktop inspection window now shares the renderer; static models.ini assembly now loads multiple models. A native car/track inspection session now displays BMW on Drift with an independent car pose. The rigid-body kernel adds explicit 3D inertia, fixed ticks and coupled spring/damper links. Suspension source records load independently; DWB and STRUT raw-design geometry now solve with explicit constraint residuals. Original suspension kinematics validation remains work ahead. Original material fidelity, vehicle force laws and FFB remain work ahead.

Physics workbench

Coupled chassis-point impulses now account for free suspension travel, wheel spin and moving-rack work. An original numeric fixture verifies effective mass and passive normal restitution. The static WALL impact diagnostic now connects finite 3D patches to simultaneous inelastic chassis contact with Coulomb friction and an energy report. It leaves positions unchanged. A separate continuous geometry query now checks prescribed translation and rotation, including intermediate wall crossings. The first-event diagnostic now stops the retained numerical physics path and applies a coupled impulse atomically. The first-event example now passes a 1e-7 m/s contact tolerance using a joint-normal candidate. Certified whole-path departure now allows separated initial proximity and force-free remainders to advance. Persistent contacts and the full driving collision loop remain incomplete.
