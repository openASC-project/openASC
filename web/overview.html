A project at the beginning

Inventory, INI/LUT readers, static KN5 geometry loading, and a local scene viewer are available. Supported diffuse textures, approximate transparency, typed surfaces, ground queries, car configuration readers and geometric spawn checks are available. A keyboard-controlled first-drive prototype is now locally tested. Original physics and shaders remain unvalidated. Finding a file does not establish compatibility.

What is openASC?

openASC is an open-source effort to build an independent engine for Assetto Corsa content. Inspired by the approach of openOMSI, development starts with understanding file formats and validating one small scene before moving toward a first drive.

The current tools read local configurations and supported static KN5 geometry. An interactive local viewer provides camera controls and mesh inspection without changing the installation. An independent keyboard prototype now moves one local car on a track. Full simulator and mod compatibility remain long-term research goals.

Inside the first-drive prototype

Actual openASC captures from the local BMW M3 E30 / Drift test on 17 October 2026. An independent keyboard prototype with approximate materials and geometric road attachment. Wall response, suspension dynamics, wheel animation, sound and FFB remain unimplemented.

Screenshots illustrate project progress and depict locally loaded Assetto Corsa content. The source game assets are not included. Open an image for the full capture.

Try the local prototype

Python 3.10 or newer, a WebGL 2 browser and your own installation. Run from the repository root.

python -m openasc drive ./assettocorsa --car bmw_m3_e30 --track drift
