# openASC identity

Original vector artwork for the openASC project. The open circuit represents a
project built in public; the forward arrow represents driving and development.
The condensed, slanted lettering is drawn as paths, with no font dependency.

| Asset | Use |
| --- | --- |
| [Dark background lockup](openasc-dark.svg) | Dark website surfaces and README dark mode |
| [Light background lockup](openasc-light.svg) | Light website surfaces and README light mode |
| [Single-color lockup](openasc-mono.svg) | Print, stamps and one-color reproduction |
| [Transparent emblem](openasc-icon.svg) | Compact marks and custom layouts |
| [Square avatar](openasc-avatar.svg) | GitHub organization or repository avatar |
| [512 × 512 PNG avatar](openasc-avatar.png) | Upload to services that require a raster image |

All SVG files are editable source artwork. They contain paths only, without
embedded images, external resources or executable content. The avatar also uses
a rounded background rectangle. The website favicon uses the same emblem.

Use the horizontal lockup at 136 CSS pixels wide or more. Use the emblem for
smaller placements. Keep clear space of at least half the emblem's height around
standalone artwork. Preserve the proportions when resizing.

Colors: racing red `#ee2534`, charcoal `#151619`, off-white `#f4f5f7`.
The light-background version uses darker red `#df1826`.
