# openASC

Основа независимого проекта по изучению совместимости с контентом **Assetto Corsa (2014)**, вдохновлённого подходом [openOMSI](https://github.com/openOMSI-org/openOMSI).

**Статус: подготовка проекта. Игровой движок ещё не реализован.** Сейчас доступны локальный сканер каталогов контента, план разработки и статический сайт для GitHub Pages. Обнаружение файлов не означает поддержку их форматов или совместимость в игре.

## Быстрый старт

Требуется Python 3.10+; сторонних зависимостей нет.

```powershell
python tools/inspect_content.py ./assettocorsa
python tools/inspect_content.py ./assettocorsa --output reports/content.json
python -m unittest discover -s tests
```

Сканер только читает каталоги `content/cars` и `content/tracks`, отмечает наличие метаданных UI, KN5 и данных автомобилей. Он не запускает игру, не распаковывает ACD и не копирует ресурсы. JSON-отчёт содержит относительные пути к контенту. По умолчанию отчёт не сохраняется.

## Сайт

```powershell
python -m http.server 4173 --directory site --bind 127.0.0.1
```

Откройте <http://127.0.0.1:4173>. Сайт не требует npm, сборки, сторонних шрифтов или CDN; работает в подпапке репозитория GitHub Pages. Ссылки на репозиторий определяются из адреса `owner.github.io/repository/`; для собственного домена задайте `repository` в `site/config.js`.

[Публикация на GitHub Pages](docs/GITHUB_PAGES.md) · [Оценка реализуемости и архитектура](docs/FEASIBILITY.md)

## Структура

```text
site/                     Статический сайт
tools/inspect_content.py  Локальная инвентаризация контента
tests/                    Тесты сканера на искусственных данных
docs/                     Архитектура и публикация
.github/workflows/        Проверки и GitHub Pages
assettocorsa/             Локальная установка, исключена из Git
```

## Ближайшая цель

Прочитать конфигурации INI/LUT, описать небольшой проверяемый набор форматов, затем создать просмотрщик одной сцены. Собственная физика, FFB, AI, звук и сетевой режим — последующие отдельные этапы. Поддержка CSP и точное совпадение с оригиналом пока не заявляются.

Assetto Corsa — продукт Kunos Simulazioni. Проект независим. Файлы игры и моды не входят в публикуемый исходный код или сайт; для исследования используется собственная установленная копия. Новый исходный код и сайт распространяются под [MIT](LICENSE). Эта лицензия не распространяется на игру и сторонний контент. Код openOMSI здесь не используется.
